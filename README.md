# 3D Creator & Data Science Portfolio — Sudharshan NS (Jack 3D)

A 3D Creator & Data Scientist landing page built with **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Features & Highlights

- **Dark Theme Aesthetic**: Deep `#0C0C0C` background with Google Font **Kanit** (weights 300–900).
- **Hero Section**:
  - Full-screen viewport with custom `.hero-heading` gradient text (`linear-gradient(180deg, #646973 0%, #BBCCD7 100%)`).
  - Interactive **Magnet** component that smoothly follows cursor dynamics.
  - Staggered **FadeIn** entrances with Framer Motion.
  - Distinctive **ContactButton** with vibrant multi-stop gradient, inner inset lighting, and crisp white offset border.
- **Marquee Showcase**:
  - Two continuous scroll-linked rows featuring 21 motion visual showcases.
  - Optimized with passive scroll events, `willChange: 'transform'`, and bidirectional velocity transforms.
- **About Section**:
  - Four floating 3D decorative assets with directional spatial entries.
  - **AnimatedText**: Character-by-character scroll-progress opacity revelation.
  - Credentials & quick facts highlighting education (MCA, PES University), machine learning accuracy (94.5%), and cloud certifications.
- **Services Section**:
  - Clean white card transition (`#FFFFFF`) with heavy rounded top geometry (`rounded-t-[60px]`).
  - 5 numbered service blocks with fluid typographic clamps and subtle hover interactions.
- **Projects Section**:
  - 3 sticky-stacking interactive cards with dynamic scroll-driven scale transforms.
  - Real project case studies with high-resolution imagery and direct live GitHub repositories.
- **Interactive Data Flow & Contact**:
  - Real-time animated HTML5 canvas showcasing the pipeline: `Raw Data -> AI Model -> Decisions`.
  - One-click copy interactions for email, phone, and direct links to LinkedIn & GitHub.
  - Interactive mode switch allowing quick preview between **Sudharshan's Portfolio** and the **Jack 3D Template**.

## Running Locally

```bash
# Navigate to project directory
cd portfolio-3d

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
